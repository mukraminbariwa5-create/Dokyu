# Deploying Dokyu (Render + Neon, free)

One Render web service runs the API **and** serves the web app from the same address, so the sign-in
cookie stays first-party (browsers block it when the app and API are on different sites). The database is
Neon's free Postgres (it does not expire). GitHub Pages keeps hosting the always-on preview (no accounts).

## 1. Database (Neon)

1. Sign up at https://neon.com with GitHub and create a project `dokyu` in the region closest to the Philippines.
2. **Connect** → turn **Connection pooling off** → copy the connection string (`postgresql://…?sslmode=require`).

## 2. App + API (Render)

1. Sign up at https://render.com with GitHub and allow access to the `Dokyu` repo.
2. **New → Blueprint** → pick the `Dokyu` repo. Render reads `render.yaml`.
3. When asked, fill in:
   - `DATABASE_URL`: the Neon connection string.
   - `SEED_ADMIN_PASSWORD`: a long password for `admin@example.com` (keep it private).
   - `RESEND_API_KEY` and `MAIL_FROM`: leave empty unless you set up email (step 4).
4. **Apply.** The build installs, runs the database migrations, loads the guides/offices/holidays and builds
   the web app. The first build takes a few minutes. The app is then at `https://<name>.onrender.com`.

The JWT secrets are generated by Render. CORS and email links use the Render address automatically.

## 3. Things to know

- Free Render services sleep after 15 minutes without visitors; the next visit takes about a minute.
- Demo account: `demo@example.com` / `Dokyu-demo-2026` (public on purpose).
- Every push to `main` redeploys (and re-seeds content, which is idempotent).

## 4. Optional: real email (password reset, verify email)

Without email, the app says so on "Forgot password" and hides the verify banner. To turn it on, create a
free Resend account, verify a sending domain, and set `RESEND_API_KEY` and `MAIL_FROM`
(e.g. `Dokyu <no-reply@yourdomain>`) in Render.

## If the build runs out of memory

The web export needs about 400–500 MB. If Render's free build fails with "out of memory", tell Claude:
the fallback is to build the web app in GitHub Actions and let Render only copy it.
